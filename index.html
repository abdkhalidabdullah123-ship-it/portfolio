PROJECT-1  ·  DESKTOP APPLICATION

Sorting Algorithm Visualizer.

An interactive JavaFX desktop application for understanding how sorting algorithms work through animated bars, operation highlights, and live statistics.

JavaJavaFXMavenData Structures & Algorithms

About the project

Sorting algorithms are easier to understand when you can watch each comparison, swap, and write. This app visualizes those operations while letting users control playback and speed.

Key features

  • Animated sorting with highlighted operations
  • Start, pause, resume, reset, and generate array
  • Adjustable speed and live operation statistics
  • Resizable visualization with different array sizes

Sorting algorithms

Bubble Sort · Selection Sort · Insertion Sort · Merge Sort · Quick Sort
