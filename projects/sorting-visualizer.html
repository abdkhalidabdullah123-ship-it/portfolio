Sorting Algorithm
Visualizer.

Understanding sorting algorithms, one operation at a time. An interactive JavaFX application that turns comparisons, swaps, writes and pivot selections into a visual learning experience.

01 / THE IDEA

See the logic.
Not just the result.

Sorting algorithms can feel abstract when their only output is a sorted array. This project visualizes what happens between the first comparison and the final result.

Users can generate arrays, switch algorithms, adjust playback speed, pause and resume execution, and watch the operation statistics update in real time.

02 / INTERACTIVE FEATURES

Built to make
learning visual.

01

Five Algorithms

Bubble, Selection, Insertion, Merge and Quick Sort, each animated operation by operation.

02

Playback Control

Start, Pause, Resume, Reset and Generate Array controls support deliberate exploration.

03

Adjustable Speed

Change animation speed from 0.25× to 20×, including while sorting is in progress.

04

Live Statistics

Track comparisons, swaps, writes, pivot selections and total operations.

05

Dynamic Arrays

Generate arrays from 10 to 100 elements in a responsive, resizable desktop layout.

06

Operation Highlights

Distinct colors identify comparisons, swaps, writes, pivots and successful completion.
